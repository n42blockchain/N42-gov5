2. **EIP-4444 近窗保留 + 冷段卸载**（Full 节点标准）：
   - `internal/ethel/historyexpiry`：保留策略（1yr 窗口，冷/热边界）。
   - `cmd/n42-history-expiry`：`--mode cdat`（relocate 列式段，比 era 紧 2.5×）/`--mode era`。
   - 实测：全链 body 567GB → Full 留 **91.5GB 热（−84%）**，冷 cdat 0000..0282=475.9GB。
   - `internal/ethel/coldseed`（`n42-cold-seed`）：archive seed 全部文件（header+body+receipts），sealed 幂等、active 周更新。
   - `internal/ethel/coldresolve`：透明冷读 resolver（`ErrBodyTrimmed`→fetch）+ TorrentFetcher（1-of-N）+ receipts freezer-hook resolver + archive DownloadAll。
   - **真跑**：1-of-N 单段 77ms PASS；archive 全量 DownloadAll 3 段 PASS。
   - 修复 torrent 2 bug：`SeedContent` 不写盘 / `NewClient` 忽略 ListenAddr。

3. **F2 去签名 body 格式**（`internal/ethel/bodyf2`）：
   - 列式 codec（全 tx 类型：legacy/accesslist/dynamic/blob t3/setcode t4 + withdrawals），value 科学计数法，AddrDict 全局地址字典。
   - `Writer/Reader` store（f2.cidx+cdat+addr.dict）+ MPHF hash 索引 + 可选 txhashes sidecar。
   - `cmd/n42-bodyc-f2`：真实转换，`--senders`（免 ecrecover，I/O-bound 16s/段）、`--write`、`--txhashes`、`--stream`（OOM-safe 全量）。
   - 实测：F2 **82.1 B/tx（−44.8%）**，From/Value/blob/auth vs 源 0 mismatch。

4. **node + RPC 接线**：`cmd/eth-el --history.mode/coldmanifest/seed/f2dir`；`ethel.F2Reader/F2LedgerBody/F2TxLocByHash/F2BlockHashes`；`internal/api` getTransactionBy{Block*Index,Hash} + getBlockBy*(fullTx both) 全 F2 回退（hash 经 MPHF/sidecar，r/s/v 空，§7）。
