 基础开发
Feature 👉 功能            add a new feature
Bug     👉 缺陷 / 错误     fix a bug
Fix     👉 修复             fix login issue
Issue   👉 问题（比 bug 更广）  open an issue

🔧 代码 & 架构
Function    👉 函数
Variable    👉 变量
Parameter   👉 参数
Logic       👉 逻辑
business logic  

🔄 版本控制（Git 高频）
Commit      👉 提交代码 make a commit
Branch      👉 分支     create a branch
Merge       👉 合并     merge into main
PR (Pull Request)   👉 提交合并请求（最重要）

👀 团队协作
Review  👉 代码评审     code review
Approve 👉 通过（PR）   
Comment 👉 评论 / 提意见    

🚀 开发流程
Deploy  👉 部署 deploy to production
Build   👉 构建 build failed
Release 👉 发布版本 🧪 测试 & 运行
Test    👉 测试   unit test
Debug   👉 调试   debug the issue

🧠 实战常用句（非常重要）
你可以直接用👇这些：
I will fix this bug later
This feature is still in progress
I opened a PR, please review
The build failed
We need to deploy it today
There is an issue in production
⚠️ 中国程序员常见错误（帮你避坑）
❌ function = 功能（错）   ✔ feature 才是功能
❌ submit code            ✔ commit / push code
❌ I make a PR            ✔ I open a PR
